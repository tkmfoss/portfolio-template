3-Tier Distributed System · ML & HealthTech

AiQI (Java AQI)

Predictive environmental intelligence bridging raw meteorological data with personalized clinical vulnerability profiles.

Problem Standard weather apps present raw, generalized AQI numbers that fail to reflect individual clinical vulnerability (asthma, COPD, age) and lack forward-looking predictive advisories.
Architecture JavaFX 21 desktop GUI + Spring Boot 3 core hub (calculating Indian CPCB multi-pollutant sub-indices & Supabase PostgreSQL) + Python Flask microservice serving XGBoost/LightGBM ensembles for next-hour forecast with SHAP diagnostics.

AI-based real-time air quality risk assessment and personalized clinical health advisory platform. Computes Indian CPCB sub-index formulas across PM2.5, PM10, NO2, O3, CO, and SO2, and generates downloadable multi-page PDF reports via Apache PDFBox.

Java 21 Spring Boot 3 Python Flask JavaFX 21 PostgreSQL XGBoost LightGBM CPCB Standard Apache PDFBox

VR / TinyML & Edge AI · RL · Computer Vision

SignLoop

A 100% offline, bidirectional Indian Sign Language bridge connecting Deaf signers and hearing individuals in virtual reality.

Problem Deaf and Hard-of-Hearing individuals face communication barriers in collaborative VR/XR. Existing tools rely on high-latency cloud APIs, single-word fingerspelling, or unidirectional translation.
Architecture Sign-to-Speech uses MediaPipe Holistic (225 coords/frame) + 2-layer BiGRU with temporal attention and REINFORCE RL policy (263 AI4Bharat classes) feeding Piper TTS. Speech-to-Sign uses whisper.cpp STT driving a procedural Unity 6.3 avatar (TwoBoneIK & 0 GC ARKit blendshapes).

Offline two-way Indian Sign Language (ISL) communication system in VR for Meta Quest 3 and PC VR. Re-engineered frame loops in C# without LINQ or dynamic allocations to guarantee consistent 90 FPS on standalone mobile XR chipsets.

Unity 6.3 LTS Meta Quest 3 PyTorch Gymnasium (RL) BiGRU + Attention MediaPipe Holistic whisper.cpp Piper TTS

Full-Stack Web App · Systems Ecology Simulation

WildBond

Reimagining social matchmaking through trophic ecological constraints and bio-environmental sustainability.

Problem Traditional matchmaking algorithms optimize solely for superficial human preferences, ignoring the foundational mechanics that govern relationships in natural networks: resource availability and ecological balance.
Architecture Heuristic ecological algorithm evaluating habitat overlap, trophic conflict, and circadian cycles. Dynamic season simulator modulates caloric scarcity with pack resilience bonuses, yielding an explainable Trophic Stability Score (0–100%).

Educational systems simulation web application developed by Team Code Crypters (Jobin M John — Team Lead · Full Stack · System Design). Built with React 18, Vite, and Node.js featuring real-time seasonal UI and audio transitions.

Chaos IDE

An adversarial speedrun coding arena where developers race against an unhinged local LLM that actively sabotages their code.

Problem Modern developers have grown overly reliant on agreeable autocomplete AI assistants that spoon-feed answers, removing the debugging challenge from programming.
Architecture Monaco Editor with timed mutation waves vs Safe Mode countdowns. Powered by a dual-tier sabotage pipeline (quantized Ollama qwen2.5-coder:7b with 1.2s abort timeouts + AST regex fallback) and client-side Pyodide WebAssembly terminal.

Gamified coding platform built for TinkerHub Useless Projects 3.0 by Team Buggers (Jobin M John, Mohamed Fahad Lal). Features non-blocking in-browser CPython 3.12 WebAssembly test execution and real-time local LLM code sabotage with retro mainframe styling.
