# Project Cover Screenshots & Previews

Drop your project cover screenshots or media directly into this folder:

- `aiqi.png` (or `.jpg`) — Cover screenshot for AiQI
- `signloop.png` (or `.jpg`) — Cover screenshot for SignLoop
- `wildbond.png` (or `.jpg`) — Cover screenshot for WildBond
- `chaos-ide.png` (or `.jpg`) — Cover screenshot for Chaos IDE

### How it works:
- If a screenshot file exists with these names, the portfolio website will automatically display it in the project card preview header with hover zoom.
- If the file is not yet added, the website automatically falls back to an abstract SVG system architecture blueprint.
- Hovering over cards triggers the 3D interactive tilt effect and displays the "▶ Watch Video Demo" overlay button linking directly to the demo.
